# 과제함 60초 홍보 영상

「과제함 홍보 영상 제작 지침서」(2026-10, 앱 판 2026-10-07b 기준)를 바탕으로 만든 60초 메인 광고(가로 16:9, 1920×1080, 60fps)입니다.
완성본은 `out/gwajeham-60s.mp4`에 있습니다.

- 색과 글꼴은 지침서 07장 그대로입니다(바탕 `#313338`, 카드 `#2b2d31`, 강조 파랑 `#5865F2`, 운호스터디 `#161826`/`#9184d9`, 숫자 Archivo 800, 한글 Pretendard 700/800).
- 움직임은 0.25~0.45초 감속, 여러 개는 0.06초 간격으로 들어가고, 3번 넘게 번쩍이는 효과는 쓰지 않았습니다.
- 소리 없이 봐도 이해되도록 모든 장면에 자막을 넣었습니다.
- AI·잠금·화질 표현은 11장 기준을 따랐습니다("확인하고 넣기만", "개인 공간의 글은 내 비밀번호로 잠겨요", "낮은 화질로 먼저 공개, 높은 화질은 이어서").

## 다시 만들기

```bash
cd promo
npm install                 # playwright, qrcode
pip install numpy scipy     # 음악 합성
node render.mjs --fps 60                          # → out/gwajeham-60s.mp4 (4코어 기준 약 5분)
node render.mjs --url https://주소                 # 끝 장면에 주소 + QR 넣기
node render.mjs --still 14,30,58                  # 원하는 시각의 정지 화면만 out/stills/ 에 저장
node render.mjs                                   # 30fps 빠른 확인용 (약 2분)
```

- `index.html`: 모든 장면. `window.render(t)`가 시각 `t`초의 화면을 그립니다. 브라우저로 열고 콘솔에서 `render(14)`처럼 확인할 수 있습니다.
- 자막 문구는 `index.html`의 `CAPS`, 효과음 위치는 `cue(...)` 호출에 있습니다.
- `music.py`: 120 BPM 전자음 배경음악과 효과음을 직접 합성합니다(외부 음원 없음, 저작권 문제 없음).
- `assets/img/`: 지침서 PDF에 들어 있던 실제 앱 캡처(시연용 데이터)와 학교 문장입니다.
- `assets/fonts/`: Pretendard, Archivo (둘 다 SIL OFL, 라이선스 파일 동봉).

## 공개 전에 확인할 것

- **주소와 QR**: 지침서에 실제 접속 주소가 없어서 끝 장면에 넣지 않았습니다. `--url`로 다시 렌더링하면 들어갑니다.
- **학교 문장·학교 이름**: 지침서 07·11장대로 선생님 허락을 받은 뒤 공개하세요.
- **몽타주(0:20–0:24)**: 공지함·과제 자료·시험 달력·투표·출석부는 지침서에 캡처가 없어서 실제 메뉴 이름과 기능 설명을 글자로만 보여 줍니다. 실제 화면 녹화가 생기면 그 장면을 바꾸는 것이 지침서 06장 원칙("실제 화면이 주인공")에 더 맞습니다.
- **휴대폰 장면**: 세로(9:16) 판과 30초·15초 판은 아직 만들지 않았습니다.
