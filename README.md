# 운호스터디 (UNHO Study)

운호고등학교 학생이 직접 강의 영상을 올리고 함께 보는 동영상 강의 사이트입니다.
기획 와이어프레임(가로기준 메인화면 / 강의 업로드 화면 / 플레이어) 기준으로 구현했습니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

Node.js 22.13+ 필요 (내장 `node:sqlite` 사용). 환경변수: `PORT`, `DATA_DIR`(DB 위치), `UPLOAD_DIR`(영상/썸네일 저장 위치).

## 화면별 기능

| 화면 | 기능 |
|---|---|
| 메인 (`/`) | 프로필 카드(연속접속일수·수강중인강좌), 프로필수정/로그아웃/즐겨찾기/강의 업로드, 과목·세부분류 사이드바, 강의 검색, 4열 강의 카드(업로더 · 날짜 · 조회수) |
| 업로드 (`/upload.html`) | 미리보기, 파일 선택/끌어놓기, 제목·설명, 시리즈/폴더분류/연속강의(회차) 설정, 자막 편집기(직접 입력, 현재 재생위치 입력, SRT/VTT 불러오기), 임시저장·업로드 |
| 플레이어 (`/watch.html?id=`) | 10초 앞/뒤, 재생바, 배속, 전체화면, 설정(화질·자막 켜기/끄기·크기), 설명란, 업로더 프로필, 이어지는 강좌(시리즈), 이어보기, 다음 회차 자동 이동 |

단축키: Space 재생/정지, ←/→ 10초 이동, F 전체화면.

## 참고

- 화질 설정은 UI만 있고 현재는 원본 화질만 재생됩니다 (다중 화질은 서버 트랜스코딩이 필요).
- 썸네일은 업로드 시 영상의 한 장면에서 자동 생성되며 "썸네일" 버튼으로 다시 지정할 수 있습니다.
